Sobre el proyecto

Diario de Construcción

Web Slinger es un juego de balanceo con telarañas construido en Three.js desde cero, usando un gauntlet loop: un ciclo continuo de build → critique → fix en el que tres agentes de IA colaboran.

Opus actúa como orquestador y toma las decisiones arquitectónicas. DeepSeek V4 Flash construye cada sistema: ciudad procedural, física de balanceo, cámara, efectos y pulido visual. GPT-5.5 critica la implementación contra material de referencia real, frame a frame, y rechaza cualquier resultado que no alcance calidad AAA.

Este diario documenta cada loop, sus iteraciones y las evidencias de rendimiento y determinismo que validaron el resultado final.

El Prompt

Prompt adaptado del Gauntlet Challenge, enfocado en un juego de Spider-Man en Three.js con ciclo de builder + critic agents.

I want you to build a Spider-Man web-swinging game at the level of the most recent Spider-Man games. It should be utterly perfect, visually beautiful, with every single thing done at an AAA quality—from physics to feel to city density. El prompt pide calidad AAA pero con un scope acotado: web-swinging, no un juego completo. Fan out sub-agents and have sub-agents tackle each one individually so that the game is perfect. You should loop on each item and have a separate sub-agent check it visually to ensure it looks triple A. That separate sub-agent should be a really harsh critic, and if it doesn't look triple A, it should keep going. El patrón Gauntlet: builder + critic separados. El critic es "really harsh" — no aprueba mediocridad. Don't stop until each sub-agent is utterly wowed with the quality when compared with the actual Spider-Man game. It should literally compare them side by side and say which one looks better. Do this in ThreeJS. Loop until it's utterly perfect. Fan out sub-agents and ultracode.
La clave: comparar contra material de referencia real (Spider-Man 2 PS5), no contra una opinión subjetiva.

Contrato de Comunicación

Los agentes nunca importan entre sí. Se comunican únicamente a través de src/contracts/index.ts, que define la interfaz AnchorQuery. Esto permite que la ciudad pueda ser reemplazada sin tocar el sistema de balanceo.

El Ciclo de Iteración

Cada sistema pasó por múltiples rondas de build → critique → fix. DeepSeek V4 Flash implementaba, GPT-5.5 comparaba contra el material de referencia y emitía un veredicto con evidencia, Opus coordinaba el flujo.

DeepSeek V4 Flash implementa → GPT-5.5 revisa → FAIL + feedback → DeepSeek V4 Flash corrige → PASS ✓

Ciudad Procedural

2 iteraciones

ITER1: Overflow de capacidad en InstancedMesh, chunks sin optimizar. Critic found GPU buffer leak.
ITER2: Chunk streaming corregido, budgets within limits. PASS.

Traversal / Swing

4 iteraciones

ITER1: Péndulo inestable, release errático.
ITER2: Fixed-step solver, mejora en attach.
ITER4: Dash dirigido + dive funcionando. PASS.

Camera / FX

1 iteración

ITER1: Cámara chase con springs críticos, FOV curve, speed streaks. Aprobado directamente contra referencia.

Integración

5 waves

Waves de integración verificaron que todos los sistemas funcionan juntos. Cada wave = rebuild + full capture suite.

EJEMPLO: CITY_ITER1 → CITY_ITER2

Critic found: "Chunk streaming leaks GPU instance buffers without bound — capacity overflow at 2.8k blocks."
Builder fix: Implemented chunk recycling, capped instance buffer allocation, added frustum-cull per chunk.
Critic re-review: "All budgets pass with headroom. PASS." — Evidenced by capture run showing 73 draw calls, 581k triangles, 23MB heap.

2 PASS / 5 FAIL / 2 BLOCKED

6 PASS / 0 FAIL / 3 BLOCKED

Flip: State-exact resolution → 0° en frame de contacto (PASS).

Blocked: Traversal non-determinism propaga a visit numbering.

EJEMPLO: ANIM_ITER1 → ANIM_ITER2 — FLIP FIX

Critic found: "Hero emits 214.7° of flip pitch entering WALL_RUN. The old resolve mechanism accelerates a cut-short flip over 0.18s, leaking intermediate pitch into contact states."
Builder fix: State-exact resolution — first non-airborne frame IS the whole turn, pitch/roll zero from that frame. Three independent gates: FlipController zeroing, isSurfaceContactState at rig application, MotionSample zeroing.
Critic re-review: "Flip pitch on WALL_RUN contact frame: 0.0°. PASS."

EJEMPLO: CITY_ATMO_ITER2 — FOG CONTINUITY

Critic found: "Fog discontinuity at y=20/y=80 produced a 'featureless pale field' above and 'brown-mauve void' below. Skyline at 235m showed zero layered depth."
Builder fix: Camera-driven fog via onBeforeRender. Continuous smoothstep(alt, 8, 150), eased altitude (0.35s tau), rate-limited output. Night fog scales: near 0.6, far 0.95.
Critic re-review: "Skyline shows multiple ranks of towers extending to the horizon with layered depth. The single biggest quality gain in the project's history. 21 PASS, 2 PARTIAL."

Flip Resolution — Telemetría

State-Exact Flip Fix (P0)

Antes (ITER1): Hero emitía 214.7° de flip pitch al entrar a WALL_RUN. El mecanismo anterior aceleraba un flip acortado sobre 0.18s, filtrando pitch intermedio a estados de contacto.

Fix: Resolución state-exact — el primer frame no-airborne ES el giro completo. Pitch/roll = 0° desde ese frame. Tres puertas independientes: FlipController zeroing, isSurfaceContactState en rig application, MotionSample zeroing.

Después (ITER2): Flip pitch en frame de contacto de WALL_RUN: 0.0°

Fog Before / After

Antes — Fog Discontinuo

Discontinuidad en y=20/y=80. Campo pálido sin features arriba. Void marrón-mauve abajo. Skyline a 235m sin profundidad layered. Cada camera altitude creaba un "cut" visible.

Después — Fog Continuo

Smoothstep continuo altitud (8-150m). Skyline muestra múltiples rangos de torres hasta el horizonte con profundidad layered. "The single biggest quality gain in the project's history." — GPT-5.5 Critic

Ground Textures

Asfalto (Roads)

Pavimento (Sidewalks)

Textura procedural con disposal pipeline. Triple-multiply bug fix: el color del material no debe multiplicar la textura. Disposal en cierre de chunks.
